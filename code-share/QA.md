## 部署与线上检查

- 独立 Worker：`cloud-mail-code-share`；对外域名：`codes.sisyphusx.com`，保留 workers.dev 备用入口。
- 独立授权数据库：`mail-code-share`。原邮件库只被 SELECT 查询，没有改动邮箱所属用户或旧邮件。
- 部署后再次查询账号归属，和部署前一致；接口代码不包含向 MAIL_DB 写入的路径。
- 健康接口 HTTP 200；HTTPS 页面 HTTP 200，CSP、no-store/no-transform、no-referrer、noindex 均已核对。
- 正确分享口令登录 HTTP 200，Cookie 为 Secure / HttpOnly / SameSite=Strict / 900 秒。
- 无会话取码 HTTP 401；指定其他邮箱查询 HTTP 400；普通会话访问管理员接口 HTTP 401。
- 创建一份单独的临时验收授权，登录后由管理员撤销；原 Cookie 请求返回 HTTP 403。临时验收授权保留为已撤销记录，没有影响交付给用户的有效授权。
- 所有真实密钥、具体邮箱授权、部署账号/数据库 ID、交付链接和口令位于 gitignore 路径。公网静态目录不包含这些文件。

## 已知边界

- 只提供授权创建后的新邮件，不提供之前的历史验证码。
- 口令和链接共同授权访问；复制出去的验证码无法通过撤销收回。
- 会话最长 15 分钟，长时间停留后需要重新输入访问口令。
- 同一份授权所有浏览器共享每 5 秒一次、北京时间每日 500 次的查询预算。
- MAIL_DB 的平台绑定不是数据库级只读权限，代码和测试约束它只执行 SELECT。
